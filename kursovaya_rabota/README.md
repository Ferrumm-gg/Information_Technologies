# Курсовая работа

Проект по техническому заданию компании в **отдельном репозитории**,
описание работы и защита презентацией до 7 минут.

## Что сдаётся

| Что | Где |
|---|---|
| Сайт по ТЗ с GA4, UTM-ссылками, формой заявок и автоответом в Instagram | отдельный репозиторий проекта |
| Описание работы | `docs/opisanie.md` в репозитории проекта |
| Презентация к защите (до 7 минут) | PDF в репозитории проекта |
| Ссылки на всё перечисленное | бланк [kursovaya.md](kursovaya.md) в этой папке |

## Порядок

1. Получить номер ТЗ и создать отдельный репозиторий проекта.
2. Сделать сайт, подключить GA4, события, UTM-ссылки, форму заявок и таблицу.
3. Собрать отчёты GA4 и дашборд DataLens.
4. Написать описание работы и подготовить презентацию.
5. Заполнить бланк [kursovaya.md](kursovaya.md) и выдать доступы преподавателю.
